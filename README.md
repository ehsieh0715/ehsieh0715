### ⚡ [Energy Analytics Engineering with dbt](https://github.com/ehsieh0715/energy-analytics-dbt)

![dbt](https://img.shields.io/badge/dbt-Dimensional%20Modelling%20%7C%20Testing%20%7C%20Lineage-FF694B?logo=dbt&logoColor=white)
![DuckDB](https://img.shields.io/badge/DuckDB-Local%20Warehouse-FFF000?logo=duckdb&logoColor=black)
[![dbt CI](https://github.com/ehsieh0715/energy-analytics-dbt/actions/workflows/dbt-ci.yml/badge.svg)](https://github.com/ehsieh0715/energy-analytics-dbt/actions/workflows/dbt-ci.yml)

Analytics engineering project that transforms simulated raw energy data into tested and documented dimensional models using **dbt and DuckDB**.

### ☁️ [Stroke Risk Analytics on AWS](https://github.com/ehsieh0715/stroke-risk-analytics-aws)

![AWS](https://img.shields.io/badge/AWS-S3%20%7C%20Glue%20%7C%20Athena%20%7C%20EC2-232F3E?logo=amazonwebservices&logoColor=white)

Cloud analytics pipeline using **Amazon S3, AWS Glue, Glue Crawler, Athena, EC2, and Grafana** to transform healthcare data into interactive analytical views.
